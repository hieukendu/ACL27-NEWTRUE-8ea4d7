# Provenance of every reported number (final, rounds 1–3)

Layout: run code from `artifact/`; LaTeX lives in `manuscript/`. Every in-text number is a LaTeX macro in `manuscript/numbers_v2.tex` (main results), generated by `code/make_tables_v2.py` from `results/analysis/v2.json` (`code/analyze_v2.py`). A few appendix macros (template sweep, re-test, cutoffs, prompt counts) are in `manuscript/numbers.tex`, generated by `code/make_tables.py` from `results/analysis/main.json` (`code/analyze_main.py`). Round-2 additions: `manuscript/numbers_v3.tex` (main test with entity triples, all item groups, held-out labels, larger models) is generated by `code/make_tables_v3.py` from `results/analysis/v3.json` (`code/analyze_v3.py`). Never edit the numbers files by hand.

## Upstream
- Generations: `code/run_generate.py <model> [--conds ...] [--items data/items_ancient.jsonl] [--maxnew 256] [--sweep]` → `results/gen/<model>[_anc|_long|_sweep].jsonl`. GPU queues: `code/run_pipeline*.sh` (logs `results/pipeline*.log`).
- Labels: `code/judge.py {qwen2.5-7b|mistral-7b} <gen files>` and `code/judge_api.py <gen files>` (Claude Haiku 5.5; key from `$ANTHROPIC_API_KEY` or the file named by `$ANTHROPIC_KEY_FILE`, never logged; `judge_openai.py` likewise reads `$OPENAI_API_KEY` / `$OPENAI_KEY_FILE`) → `results/labels/<judge>/`.
- Items: `fetch_wikidata.py → build_transitions.py → build_items.py → validate_items.py`; `build_ancient.py` (ANC); audit: `audit_items.py` (flags), `audit_wiki.py` and `audit_reinstate.py` (Wikipedia leads), verdicts in `results/audit/verdicts.json`, exclusions in `data/exclusions.json`.
- Probes: `code/run_probe.py`, `code/run_verify.py`.
